\section{PS7: \textit{All} the derivative shortcut rules!}

\textbf{Introduction:} 
In this Problem Set, you'll show how to find derivatives \textbf{step-by-step}, carefully listing out all of your steps, and using good derivative grammar. 
\begin{itemize}
    \item I am going to be so annoying about making you take \textbf{very small steps}, because it's a good way to get comfortable with all the shortcut rules.
    \item I am also going to be so annoying about \textbf{good grammar}, because thinking carefully about what letter is the variable is important (and will be even more important next chapter).
    \item Lastly, I am going to be so annoying about \textbf{PEMDAS issues}, because it is important for us to understand that \[2y + 4 \cdot (\cos(y))\] is not the same as \[(2y + 4)\cdot(\cos(y)),\] but it is even more important for us to understand \textbf{why}.
\end{itemize}

\hrulefill

\textbf{Instructions:}
For each problem you choose:
\begin{enumerate}[(a)]
	\item Refer to the reference list of shortcut rules to identify \textbf{all} the derivative rules you're going to need to use for your problem.
    \begin{itemize}
        \item Watch out for the sneaky structure rules that you use without even noticing them!
    \end{itemize}
    \item Make your sheet of paper into two columns. 
    \begin{itemize}
        \item In the left column, do tiny derivative steps. 
        \item In the right column, list all the rules you are using in that step.
        \item Look at the example on the back of the reference list page (the one we did as a warmup on Thursday) to see how tiny your steps should be.
    \end{itemize}
	\item Repeat with a new problem until you have checked off \textbf{all 12 of the shortcut rules} in the reference list at least once.
    \begin{itemize}
        \item Yes, all three of the rules for trigonometric functions count separately.
        \item I am pretty sure you will need to do at least five problems.
        \item If you do extra problems, I will give you a sticker.
    \end{itemize}
\end{enumerate}
Throughout, label your work with derivative signs, using correct derivative notation and grammar.

\textbf{(Example)} Find $\dfrac{dp}{dt}$ if 
$p(t) = \dfrac{\cos(t^2-1)}{e^{-3t}}$.

\vspace{1em}

I am going to need the following derivative rules:
\begin{multicols}{3}
	\begin{itemize}
		\item quotient rule
		\item chain rule
		\item sum rule
		\item constant multiple rule
		\item trig function rule \\
        (the one for $\cos(\ldots)$)
		\item power function rule
		\item constant function rule
		\item exponential function rule
	\end{itemize}
\end{multicols}
Now, explain what rules are happening in each step, as highlighted by the blue boxes. 
{\renewcommand{\textrm}{\textcolor{white}}
\begin{align*}
\textbf{Steps}& 
& \textbf{Rules} \\\hline
&&\\
\frac{dp}{dt} &= \frac{[e^{-3t}]\cdot \diff{t}[\cos(t^2-1)] - 
					   [\cos(t^2-1)]\cdot \diff{t}[e^{-3t}]}
					  {[e^{-3t}]^2}
& \textrm{(quotient rule)} \\ \\
&= \frac{[e^{-3t}] \cdot \diff{t}[\cos(t^2-1)] - 
         [\cos(t^2-1)]\cdot
         \blue{[e^{-3t}\cdot\diff{t}[-3t]]}}
		{[e^{-3t}]^2} 
& \textrm{(chain rule, } \\ 
&& \textrm{exponential function rule)} \\ \\
&= \frac{[e^{-3t}] \diff{t}[\cos(t^2-1)] - 
         [\cos(t^2-1)]\cdot 
		 [e^{-3t}\cdot\blue{(-3)}]}
		{[e^{-3t}]^2} 
& \textrm{(constant multiple rule, } \\
&& \textrm{power function rule)} \\ \\
&= \frac{[e^{-3t}] \cdot
         \blue{\left[-\sin(t^2-1)\cdot\diff{t}(t^2-1)\right]} - 
		 [\cos(t^2-1)]\cdot 
         [e^{-3t}\cdot(-3)]}
		{[e^{-3t}]^2}
& \textrm{(chain rule, } \\
&& \textrm{trig function rule)} \\ \\
&= \frac{[e^{-3t}] \cdot
         [-\sin(t^2-1)\cdot 
         \blue{\left[\diff{t}(t^2) - \diff{t}(1)\right]}] - 
		 [\cos(t^2-1)]\cdot 
         [e^{-3t}\cdot(-3)]}
		{[e^{-3t}]^2}
& \textrm{(sum rule)} \\ \\
&= \frac{[e^{-3t}] \cdot
         [-\sin(t^2-1)\cdot \blue{(2t-0)}] - 
		 [\cos(t^2-1)]\cdot 
         [e^{-3t}\cdot(-3)]}
		{[e^{-3t}]^2}
& \vspace{-2em} \textrm{(power function rule,} \\
&& \vspace{-2em} \textrm{constant function rule)}
\end{align*}
%\vspace{-1em}

And now I am done, because I have no more ``please take the derivative of'' signs left. Yay!

\section{Reference list of derivative shortcut rules}

Here is the list of all the shortcut rules we've learned. Check them off as you use them. 

Keep this list for reference!
{ \everymath{\displaystyle}
    \subsubsection*{Structure rules}
    \begin{itemize}[label=\(\square\)]
        \item sum rule: $\diff{x}[f(x)+g(x)] = \diff{x}[f(x)]+\diff{x}[g(x)]$ 
        \item constant multiple rule: $\diff{x}[c\cdot f(x)] = c\cdot\diff{x}[f(x)]$
        
        \item product rule: $\diff{x}[f(x) \cdot g(x)] = \diff{x}[f(x)] \cdot g(x) + \diff{x}[g(x)] \cdot f(x)$
        \item quotient rule: $\diff{x}\left[\frac{f(x)}{g(x)}\right] 
        = \frac{g(x) \cdot \diff{x}[f(x)] - f(x) \cdot \diff{x}[g(x)]}{[g(x)]^2}$
        \item chain rule: $[f(g(x))]' = f'(g(x)) \cdot g'(x)$, or in other words, $\dfrac{d}{dx}\left[ f(g(x)) \right] = f'(g(x)) \cdot \dfrac{d}{dx}\left[ g(x) \right]$
        
    \end{itemize}

    \begin{minipage}{0.55\textwidth}
        \subsubsection*{Function rules}
        \begin{itemize}[label=\(\square\)]
            \item constant function rule: $\diff{x}[c] = 0$
            \item power function rule: $\diff{x}[x^n] = nx^{n-1}$
            \item exponential function rule: $\diff{x}[a^x] = a^x\cdot\ln(a)$
            \item[] trigonometric function rules: 
            \begin{itemize}[label=\(\bigcirc\)]
                \item $\diff{x}[\sin(x)] = \cos(x)$
                \item $\diff{x}[\cos(x)] = -\sin(x)$
                \item $\diff{x}[\tan(x)] = \sec^2(x)$
            \end{itemize}
            \item logarithmic function rule: $\diff{x}[\ln(x)] = \frac{1}{x}$
        \end{itemize}
    \end{minipage}
    \fbox{
    \begin{minipage}{0.45\textwidth}
        \section{Some extra function rules} 
        These ones are not on this homework and generally come up less frequently, but I would get points on my math license if I didn't at least say them.
        \begin{itemize}[leftmargin=15pt, label=\(\centerdot\)]
            \item inverse trigonometric function rules: 
            \begin{itemize}[label=\textopenbullet]
                \item $\displaystyle \diff{x}[\arctan(x)] = \frac{1}{1+x^2}$
                \item $\displaystyle \diff{x}[\arcsin(x)] = \frac{1}{\sqrt{1-x^2}}$
            \end{itemize}
            \item rules for other trigonometric functions:
            \begin{itemize}[label=\textopenbullet]
                \item $\diff{x}[\cot(x)]=-\csc^2(x)$
                \item $\diff{x}[\sec(x)]=\sec(x)\tan(x)$
                \item $\diff{x}[\csc(x)]=-\csc(x)\cot(x)$
            \end{itemize}
        \end{itemize}
    \end{minipage}
    }
